# Roadmap

## Goal

Provide a living view of planned capabilities.

## Near Term

1. Complete documentation polish and keep pages synchronized with UI behavior.
2. Expand typed socket coverage across all node categories.
3. Improve interactive-node UX consistency (clear prompts, robust validation, predictable cancel behavior).
4. Strengthen batch workflow ergonomics (CSV authoring guidance, dynamic parameter discoverability).
5. Stabilize video node workflow and axis/rotation usability defaults.
6. Increase automated test coverage for UI-adjacent regressions.

## Mid Term

1. Add reusable workflow templates and examples for common bioimage tasks.
2. Improve observability: optional per-node timing, execution summaries, lightweight profiling output.
3. Extend I/O interoperability (richer import/export patterns, better metadata preservation).
4. Improve macro ergonomics (editing, naming, boundary/socket management).
5. Improve plugin distribution readiness and environment diagnostics for optional capabilities (for example interactive plotting backends).

## Long Term

1. Establish robust, reproducible analysis profiles for large-scale spatial omics workflows.
2. Strengthen collaborative workflow sharing (portable pipeline packs + dataset parameterization conventions).
3. Extend control-flow abstractions while preserving visual clarity and deterministic execution semantics.
4. Explore optional cloud/HPC-oriented execution backends for very large studies.
5. Evolve documentation into a complete user + developer handbook with maintained examples and benchmark references.

## Notes

- Roadmap items are directional and may be reordered as priorities change.
- Each release should map shipped work back to this page and to `reference/changelog.md`.
