# Napari Flow Editor Documentation

Visual pipeline building for napari with data flow, control flow, loops, macros, batch runs, and video export.

## How To Use This Documentation

- Start with **Getting Started** if this is your first time using the plugin.
- Read **Core Concepts** to understand how execution and data movement work.
- Use **Guides** for task-focused workflows.
- Use **Node Catalog** as a manual reference while building pipelines.
- Use **Troubleshooting** when something behaves unexpectedly.
- Use **Developer** docs if you are extending the plugin.

## Documentation Status

This is a living manual for users and developers.

It is designed to be updated as features evolve:
- keep screenshots in sync with UI changes
- update node references when library metadata changes
- add troubleshooting entries from real user issues
