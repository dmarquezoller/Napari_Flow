# Node Catalog

## Goal

Provide a manual, curated reference of available nodes.

## How To Maintain This Section

Use these rules when updating node docs:

1. Update this section whenever a node is added, renamed, or removed.
2. Keep node pages grouped by user intent, not only by internal module files.
3. Prefer short practical descriptions over full signatures.
4. Add usage caveats only when they prevent common mistakes.
5. Keep examples aligned with current socket names shown in the UI.

## Categories

- Input Nodes
- Processing Nodes
- Control Flow Nodes
- Output and Visualization Nodes

## Current Coverage Scope

This catalog is intentionally manual and curated.

It summarizes:
- what each node family is for
- where each node fits in pipeline design
- practical notes and gotchas

It does not attempt to duplicate full function-level API docs.
